# HGV Time Directive — legal documents

Public privacy policy and terms of service for the HGV Time Directive Android app.

Published with GitHub Pages: <https://rad1994.github.io/hgv-time-legal/>

The source of truth for the text is the project vault
(`00-Product/08-Privacy-Policy.md`, `00-Product/09-Terms-of-Service.md`).
`build.py` renders those markdown files into the HTML in this repository —
edit the markdown and rebuild, never the HTML directly.
